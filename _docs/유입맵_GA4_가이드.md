# 유입맵 — GA4 속성/랜딩 추가 가이드 (2026-08)

**목적**: 메타 광고가 여러 랜딩페이지(각기 다른 GA4 속성)로 갈 때, 각 유입을 `메타+`에 분리 집계.
**핵심**: 랜딩(속성)이 몇 개가 늘어도 **코드 수정 0** — `_유입맵` 시트 행 1개 + UTM 태그만.

---

## 채울 곳은 딱 2군데

1. **`_유입맵` 시트** = 속성 등록 (유입라벨 → GA4속성ID / 탭명 / 전환이벤트).
2. **UTM 시트 G열(유입구분)** = 광고그룹 태그 (그 광고그룹이 어느 유입인지).

> 베이스(리틀리/시티마켓)는 맵에 **안 넣음** = 암묵 기본(본속성 `GA4_자동` + `kakao_chat_click`).

---

## ★ 먼저 판별: 같은 속성 vs 새 속성

새 광고그룹의 slug가 **기존 `<라벨>_GA4` 탭 캠페인에 뜨는지**로 갈린다:
- **뜬다 = 같은 GA4 속성**(사이트만 같고 광고그룹만 늘어남) → `_유입맵` 안 건드림. **UTM 그 행의 유입구분(G)만** 채우면 끝. 슬러그가 GA4와 맞으면 기존 메타+ 행들도 즉시 재계산(맵-인식 수식이라 재sync 불필요).
- **안 뜬다 = 새 GA4 속성**(새 사이트) → 아래 3단계.
- 실례(2026-08): 랜딩페이지_4559/3544는 slug(meta_landing_4559/3544)가 `랜딩_GA4`에 이미 있어 = 같은 속성 → UTM 유입=랜딩만 채움(맵 무변경).

## 새 랜딩 추가 — 3단계

1. 메뉴 **➕ GA4 유입(랜딩) 신규 추가** → `_유입맵` 열림. 행 추가:
   `유입=<라벨> | GA4속성ID=<번호> | 탭명=<라벨>_GA4 | 카톡이벤트=<전환이벤트> | 세션이벤트=session_start`
2. 메뉴 **🧾 GA4 유입 수집 (별도 속성 전체)** → `<라벨>_GA4` 탭 생성·수집.
   → **이벤트 열에서 전환 이벤트명을 실제로 확인**(추측 금지, 속성마다 다름). 값이 다르면 1번 카톡이벤트 교정.
3. UTM 시트에서 **그 랜딩으로 가는 광고그룹 행**에:
   `채널=페북 / 광고그룹명 / utm_campaign=<GA4 캠페인값> / 유입구분=<라벨>`
   → 다음 sync가 `메타+`에 자동 반영(중첩 IF 라우터가 그 분기를 코드생성).

---

## 전환 이벤트 (카톡이벤트 칸)

- **콤마로 여러 개 = 합산.** 예) 랜딩 = `kakao_click,cta_click,citymall_click`.
- **속성마다 이벤트명 다름**: 본속성 `kakao_chat_click` / 사전예약·랜딩 `kakao_click` / KT `chat_click`.
- ★ 첫 수집 후 `<라벨>_GA4` 이벤트 열에서 반드시 확인.

## 메타+ 매칭 원리 (K세션 / L전환)

- 광고그룹 유입=`<라벨>` → K·L을 `<라벨>_GA4`에서 **campaign = slug(utm_campaign)** 로 SUMIFS.
- 유입 공백/베이스 → `GA4_자동`(본속성). N/O 시티마켓은 별도속성 유입이면 0.

---

## ★ 함정 (실측 기반)

- **utm_campaign 미집계 = 과소집계**: 메타(특히 Advantage+/자동)가 GA4에 캠페인을 안 넘기면
  `(cross-network)`/`(not set)`/`(referral)`로 흩어져 slug 매칭이 안 됨 → 실제보다 적게 잡힘.
  완전히 잡으려면 **광고 도착 URL에 `?utm_source=meta&utm_campaign=<값>` 명시**.
  (예: 2026-08-06 랜딩 78세션 중 `campaign=landing`으로 잡힌 건 34세션뿐, 나머지 44는 유실.)
- **이벤트 중복발화 = 과대계상**: 전환이벤트가 세션당 여러 번 찍히면 L(전환)이 부풀려짐(이벤트수 기준).
  실제 클릭자 = **세션수**와 대조(예: kakao_click 29회 / 3세션 = 세션당 ~10회 = GTM 오설정 의심).
- **유입구분은 광고그룹 행에** (채널·그룹·slug 채워진 행). 빈 행에 라벨만 넣으면 무효.
- 속성ID는 텍스트 서식(`@`)으로 (지수표기 방지). named range `UTM_INF=G:G`(F열은 메모).

## 검증법

`메타+` 해당 행 K/L = `<라벨>_GA4`의 `campaign=slug` 실측(session_start / 전환이벤트 합)과 **1:1 대조**.
(2026-08-06 랜딩페이지_3059: 메타+ K34·L5 = GA4 landing캠페인 session_start34 · kakao1+cta0+citymall4=5 → 일치 확인.)
